# Leapfrog Project

## Overview
This project is a personal coding initiative showcasing my development skills through various applications. 

### Features
- **Simple Calculator**: A user-friendly calculator for basic arithmetic operations.
- **HTML**: Very Simple HTMl & CSS Site.
- **Weather App**: Provides real-time weather updates.
- **Real-Time YouTube Clone**: Mimics core YouTube functionalities for video searching and viewing.

## Purpose
This project not only reflects my technical skills but also serves as a testament to my commitment to learning and growth in software development.

## Getting Started
To explore the applications:
1. Clone the repository.
2. Follow the setup instructions in each module's directory.
